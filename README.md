# shop-compare

Vue 3 + Pinia, built with Vite.

## Requirements

Node 20.19+ or 22.12+ (see `.nvmrc` — `nvm use` picks it up).

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run dev
```

### Compiles and minifies for production
```
npm run build
```

### Previews the production build locally
```
npm run preview
```

### Lints files
```
npm run lint
```
